# 浪屿学生组织工作台（演示版）

学生组织协同管理网页演示，提供工作台、活动管理、信息收集、任务栏、知识库、物资统计、排班与课表、成员与权限管理等界面。

## 运行

直接用现代浏览器打开 `index.html`，或用任意静态网页服务器托管。

登录页提供演示账号快捷入口。演示数据仅保存在当前浏览器的 `localStorage` 中，不会同步到其他用户或设备。

## 当前限制

- 这是前端演示版，不包含服务端、云端数据库或真实身份认证。
- AI 助手尚未接入安全的后端服务，因此暂不可用。
- 请勿录入真实成员信息、学号、联系方式或其他个人数据。
- 示例成员姓名已替换为通用称呼。

## 安全配置

模型 API 密钥不能写入浏览器端代码。正式使用前应在服务端配置密钥、身份认证和数据存储，并在服务端代理模型请求。
